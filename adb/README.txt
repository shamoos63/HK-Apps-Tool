Place Android SDK platform-tools in this folder (same layout as from Google).

Required for this app:
  adb.exe
  aapt.exe   (optional but recommended — used to read APK labels, versions, and icons)

You can copy the entire "platform-tools" directory contents here, or symlink the folder.

This "adb" directory is copied next to adbappmanager.exe when you build for Windows.
